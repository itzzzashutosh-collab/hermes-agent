---

## 🧩 INTER-AGENT ROUTING FLOW:

- **Territory Sales Officer (TSO) $\longrightarrow$ CCO Agent:**  
  Execute `/visit_done` command with parameters:
  - Dealer Qualification Status (Target counter vs. Active SEGP dealer)
  - Order Potential ($₹\text{ Value}$ and Bag volume)

  Execute `/feedback` command with parameters:

- **CCO Agent $\longrightarrow$ CFO Agent (Finance):**  
  Execute `/credit_check` command with parameters:
  - Dealer Credit Limit Request

  - PDC Cheque Verification
