### Pillar 1: Paperclip Management Layer (`adapters/paperclip/`)
- Wraps Hermes Agent as a managed corporate entity.
- Enables multi-agent task ticketing, budget caps per department, and autonomous heartbeat check-ins.
- Guarantees clear separation of concerns between departmental leads.

### Pillar 2: Supermemory Semantic Vault (`plugins/memory/supermemory/`)
- Stores persistent context across sessions:
  - Specific dealer credit histories and verbal commitments.
  - Contractor loyalty tier progression.
  - Ashutosh Sharma Sir's strategic preferences and executive decisions.
- Automatically captures every session turn into 4-hour temporal memory buckets.

### Pillar 3: Hermes Function Calling Engine (`tools/` & `agent/`)
- Enforces strict JSON Schema validation for all tool interactions.
- Enables Hermes to reliably query live ERP endpoints (`/api/erp/inventory`, `/api/erp/dealers`, `/api/erp/pricing`, `/api/erp/production`) with zero hallucination.

### Pillar 4: DSPy + GEPA Self-Evolution Engine (`evolution/`)
- Reflective evolutionary search operating on real-world execution traces.
- Log traces, propose prompt mutations, test against constraint gates, and auto-commit to `skills/`.
