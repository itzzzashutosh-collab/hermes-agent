# 📊 3. NON-NEGOTIABLE KPI TRACKING SYSTEM

Every action is logged in real-time. Unmeasured work is classified as non-existent.

$$\text{Enterprise SOP Compliance Index (ESCI)} = \frac{\text{Completed SOP Tasks}}{\text{Assigned SOP Tasks}} \times 100$$

- **Tracked Operational KPIs:**  
  1. **Total Daily Visits:** Verified via mobile GPS pin check-in.  
  2. **Trial Order Conversions:** Total SEGP 20-bag packs billed.  
  3. **Reorder Rate (%):** Active counter rotation within 15–30 days.  
  4. **Painter Acquisition Count:** Total verified WhatsApp profiles added.  
  5. **AR Cash Collection ($₹\text{ Value}$):** Daily ledger recovery vs. target.
