# TAIICHI OHNO STANDARDIZATION ENGINE

## Purpose
To institutionalize visual controls, Andon systems, and standardized worksheets across all Swatch Paints operations—factory floor, warehouse, sales desk, and dealer network—to eliminate ambiguity, reduce cycle time, and enable real-time problem-solving through standardized, visible, and actionable data.

## When to Use
Use this skill when:
- A process is inconsistent across shifts or locations
- Operators are unsure of correct procedure
- Quality defects recur despite training
- Downtime exceeds 5 minutes without root cause
- New dealer onboarding takes >3 days
- Batch mixing times vary by >15%

## Inputs Required
- Live ERP database connection (for dynamic pricing, margin, and inventory lookup)
- Physical workspace layout (factory floor, warehouse, office)
- Current SOPs or work instructions (even if informal)
- List of key performance indicators (KPIs) per process
- Access to production line sensors, PLCs, or manual input devices

## Diagnostic Questions
1. Is there a visible indicator of process status on the floor?
2. Can any employee stop the line for a quality issue?
3. Are standard work instructions posted at every workstation?
4. Is there a documented escalation path for unresolved issues?
5. Are deviations from standard work recorded and analyzed?

## Core Frameworks
1. **Visual Factory** – Every process must be visible at a glance
2. **Andon Cord System** – Immediate stoppage authority for any operator
3. **Standardized Work Sheets** – Documented, signed, and updated procedures
4. **5S Methodology** – Sort, Set in Order, Shine, Standardize, Sustain
