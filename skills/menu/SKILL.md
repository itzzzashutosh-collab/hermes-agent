🎨 **SWATCH PAINTS — HERMES COMMAND CENTER**

**📊 OPERATIONS**
`/sales` — Sales pipeline, closer strategy, dealer intel
`/finance` — P&L, collections, cash flow, expenses
`/production` — Batch output, quality, plant status
`/supply` — Stock levels, vendor status, POs in transit

**📋 REPORTING & DECISIONS**
`/reports` — Executive dashboard, KPI scorecards
`/brief` — BLUF briefing — bottom line in 3 lines

`/approve` — Submit or track approval requests
`/delegate` — Assign task with owner + deadline
`/review` — Performance review, KPI evaluation
`/deploy` — Rollout status, initiative tracking

**⚙️ SYSTEM**
`/status` — Session info, model, uptime
`/agents` — Background agents running
`/new` — Start fresh conversation session
`/stop` — Emergency stop all running tasks

**💡 HOW TO USE**
Just type any command above. Example:
`/sales` → Sales intelligence briefing
`/sop what did production complete today?`
`/escalate vendor delayed RM by 3 days`
