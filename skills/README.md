# Hermes Agent Skills Directory

This directory contains the built-in, categorized skills available to Hermes Agent.

## Structure

Skills are organized by category:
- `skills/<category>/<skill-name>/SKILL.md`

Each skill directory contains:
- `SKILL.md`: Main skill instruction file with YAML frontmatter.
- `scripts/`: Optional helper scripts and utilities.
- `templates/`: Templates used by the skill.
- `references/`: Reference documentation and guidelines.

## Available Categories
- `software-development`: Development, debugging, testing, and skill-authoring tools.
- `devops`: Deployment, infrastructure, and CI/CD tools.
- `productivity`: Task and workflow automations.
- `research`: Information retrieval and analysis tools.
- `enterprise`: Business operations, ERP, and domain-specific skills (e.g., Swatch Paints).
